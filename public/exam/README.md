# 📝 แอพทำข้อสอบการขาย บทที่ 4–8

(บทที่ 4–8) เฉลยทันทีทุกข้อ และเก็บคะแนนทุกรอบไว้ให้ดูย้อนหลัง

โดยอัตโนมัติ — ทำซ้ำกี่รอบก็แทบไม่ได้ชุดเดิม

## ความสามารถ

- **เฉลยทันที** — กดตอบแล้วรู้ผลทันที พร้อมคำอธิบายและที่มาว่าอยู่สไลด์ไหน
- **เก็บคะแนนทุกรอบ** — ดูคะแนนย้อนหลัง ค่าเฉลี่ย คะแนนสูงสุด และกราฟแนวโน้ม
- **เลือกบทได้** — ติวเฉพาะบทที่อ่อน หรือรวมทุกบท
- **ทบทวนคำตอบ** — ดูทุกข้อหลังสอบเสร็จ กรองเฉพาะข้อที่ตอบผิดได้
- **สรุปแยกตามตอนและตามบท** — เห็นว่าควรกลับไปอ่านบทไหนมากที่สุด
- **ทำต่อจากเดิมได้** — ปิดแอพกลางคันแล้วกลับมาทำต่อ ข้อสอบไม่หาย
- **โหมดมืด** และรองรับหน้าจอทุกขนาด
- **สำรองข้อมูล** — บันทึก/นำเข้าประวัติคะแนนเป็นไฟล์ JSON
- **คีย์ลัดบนคอม** — กด `1`–`4` เพื่อตอบ, `Enter` เพื่อไปข้อถัดไป

## วิธีเพิ่มหรือแก้ข้อสอบ

เปิดไฟล์ `data-chXX.js` แล้วเพิ่มลงใน array ที่ต้องการ — `id` ต้องไม่ซ้ำกับข้ออื่น

```js
// ปรนัย — answer คือ index ของตัวเลือกที่ถูก (เริ่มจาก 0)
{ id: 'm4-41', q: 'โจทย์...', choices: ['ก', 'ข', 'ค', 'ง'], answer: 2,
  explain: 'คำอธิบายเฉลย', ref: 'บทที่ 4 — ชื่อหัวข้อสไลด์' }

// เติมคำ — ใส่ ____ ตรงช่องว่าง, accept คือคำตอบที่ยอมรับได้ทุกแบบ
{ id: 'f4-11', q: 'ข้อความ ____ ต่อ', accept: ['BANT', 'บานท์'],
  hint: 'ตัวย่อ 4 ตัวอักษร', explain: '...', ref: '...' }

// จับคู่ — ต้องมี 5 ข้อต่อชุดพอดี และคำตอบในชุดต้องไม่ซ้ำกัน
{ id: 's4-04', title: 'ชื่อชุด', items: [ { q: 'คำใบ้ ____', answer: 'คำตอบ' }, /* ...อีก 4 */ ],
  ref: '...' }
```

การเทียบคำตอบของข้อเติมคำจะตัดช่องว่าง เครื่องหมายวรรคตอน และไม่สนตัวพิมพ์เล็ก/ใหญ่
(`BANT` = `bant` = `B.A.N.T.`) จึงควรใส่คำตอบที่สะกดต่างกันได้ลงใน `accept` ให้ครบ

`bank.js` มีตัวตรวจข้อมูลในตัว — ถ้า `id` ซ้ำ, `answer` อยู่นอกช่วง, ตัวเลือกซ้ำกัน,
โจทย์เติมคำลืมใส่ `____` หรือชุดจับคู่ไม่ครบ 5 ข้อ จะขึ้นเตือนใน Console ของเบราว์เซอร์
