# 📝 แอพทำข้อสอบ — 2 วิชา

แอพทำข้อสอบแบบสุ่ม ใช้ได้ทั้งคอมพิวเตอร์และมือถือ สร้างจากเนื้อหาสไลด์
เฉลยทันทีทุกข้อ และเก็บคะแนนทุกรอบไว้ให้ดูย้อนหลัง แยกตามวิชา

| วิชา | เนื้อหา | คลังข้อสอบ |
|------|---------|------------|
| 🤝 **เทคนิคการขายมืออาชีพ** | บทที่ 4 – 8 | ปรนัย 259 · เติมคำ 58 · จับคู่ 19 ชุด |
| 📈 **การจัดการการตลาดสมัยใหม่** | บทที่ 5 – 9 | ปรนัย 162 · เติมคำ 53 · จับคู่ 16 ชุด |

## โครงสร้างข้อสอบ 1 ชุด = 60 ข้อ

| ตอน | รูปแบบ | จำนวน |
|-----|--------|-------|
| 1 | ปรนัย — **5 ตัวเลือก** (ก ข ค ง จ) | 40 ข้อ |
| 2 | จับคู่คำลงช่องว่าง (2 ชุด × 5 ข้อ) | 10 ข้อ |
| 3 | เติมคำในช่องว่าง (พิมพ์คำตอบ) | 10 ข้อ |

ทุกครั้งที่กด "เริ่มทำข้อสอบ" ระบบจะสุ่มชุดใหม่จากคลังของวิชาที่เลือก และกระจายข้อ
ให้ครบทุกบทที่เลือกโดยอัตโนมัติ — ทำซ้ำกี่รอบก็แทบไม่ได้ชุดเดิม

## ข้อสอบ 2 ลักษณะ

ข้อปรนัยแบ่งเป็น 2 ลักษณะ และเลือกสัดส่วนได้เองในหน้าแรก

- **ข้อความจำ** (`type: 'recall'`) — ถามนิยาม ตัวเลข หรือองค์ประกอบตรง ๆ
- **ข้อวิเคราะห์** (`type: 'analysis'`) — ยกสถานการณ์จริงมาให้ แล้วถามว่าเข้าข่ายแนวคิดแบบใด
  มีป้าย 🔍 วิเคราะห์ กำกับบนการ์ดคำถาม

> ตัวอย่าง: *"แบรนด์เครื่องดื่มระบุกลุ่มเป้าหมายเป็นนักศึกษาและคนทำงานอายุ 18-34 ปี
> ที่เล่นกีฬาผาดโผน ฟังดนตรี เล่นเกม — การระบุแบบนี้ใช้ข้อมูลประเภทใดร่วมกัน"*

ปุ่มเลือกสัดส่วนมี 3 แบบ: **เน้นความจำ** (0% วิเคราะห์) · **ผสม** (60% วิเคราะห์ — ค่าเริ่มต้น)
· **เน้นวิเคราะห์** (100% วิเคราะห์) ถ้าคลังฝั่งใดมีไม่พอ ระบบจะดึงจากอีกฝั่งมาเติมให้ครบ 40 ข้อ

คลังข้อวิเคราะห์ปัจจุบัน: การขาย 50 ข้อ · การตลาด 63 ข้อ (รวม 113 ข้อจาก 421 ข้อปรนัย)

## ความสามารถ

- **เฉลยทันที** — กดตอบแล้วรู้ผลทันที พร้อมคำอธิบายและที่มาว่าอยู่สไลด์ไหน
- **เก็บคะแนนทุกรอบ** แยกตามวิชา — ค่าเฉลี่ย คะแนนสูงสุด กราฟแนวโน้ม กรองดูทีละวิชาได้
- **สรุปผล 3 มุม** — แยกตามตอน · แยกตามลักษณะข้อสอบ (ความจำ vs วิเคราะห์) · แยกตามบท
  พร้อมชี้ว่าควรกลับไปทบทวนบทไหนและข้อลักษณะใดมากที่สุด
- **เลือกบทได้** — ติวเฉพาะบทที่อ่อน หรือรวมทุกบท
- **ทบทวนคำตอบ** — ดูทุกข้อหลังสอบเสร็จ กรองเฉพาะข้อที่ตอบผิดได้
- **ทำต่อจากเดิมได้** — ปิดแอพกลางคันแล้วกลับมาทำต่อ ข้อสอบไม่หาย
- **โหมดมืด** และรองรับหน้าจอทุกขนาด (ทดสอบตั้งแต่ 320px)
- **สำรองข้อมูล** — บันทึก/นำเข้าประวัติคะแนนเป็นไฟล์ JSON
- **คีย์ลัดบนคอม** — กด `1`–`5` เพื่อตอบ, `Enter` เพื่อไปข้อถัดไป

## วิธีใช้

**ทางที่ 1 — เปิดจากเว็บ** (หลัง deploy)

```
https://<โดเมน>/          ← ถ้า deploy เฉพาะโฟลเดอร์นี้ (ดู netlify.toml ที่ root)
https://<โดเมน>/exam/     ← ถ้า deploy ทั้ง dist/ ของ FlowDesk
```

**ทางที่ 2 — เปิดจากไฟล์ตรง ๆ** (ไม่ต้องมีอินเทอร์เน็ต)

ก๊อปโฟลเดอร์ `public/exam/` ทั้งโฟลเดอร์ไปไว้ในเครื่องหรือมือถือ แล้วเปิด `index.html`
ได้เลย — ไม่ต้องติดตั้งอะไร ไม่ต้องรันเซิร์ฟเวอร์

**ทางที่ 3 — รันพร้อม FlowDesk ตอน dev**

```bash
npm run dev     # แล้วเปิด http://localhost:5173/exam/
```

## การเก็บข้อมูล

คะแนนทั้งหมดเก็บใน `localStorage` ของเบราว์เซอร์เครื่องนั้น ไม่ส่งออกไปที่ไหน
(คนละเครื่อง/คนละเบราว์เซอร์จะเห็นประวัติแยกกัน — ใช้ปุ่มบันทึก/นำเข้าไฟล์เพื่อย้ายข้อมูล)

| คีย์ | เก็บอะไร |
|------|----------|
| `examApp.history.v1` | ประวัติคะแนนทุกรอบทุกวิชา (เก็บสูงสุด 200 รอบล่าสุด) |
| `examApp.session.v1` | ข้อสอบที่ทำค้างไว้ |
| `examApp.prefs.v1` | วิชาที่เลือกล่าสุด บทที่เลือกของแต่ละวิชา และตัวเลือกการทำข้อสอบ |
| `examApp.theme.v1` | ธีมสว่าง/มืด |

```
public/exam/

    00-subjects.js         ลงทะเบียน 2 วิชา
    10..14-sales-chXX.js   ข้อสอบวิชาการขาย บทที่ 4-8 (ข้อความจำ)
    19-sales-analysis.js   ข้อวิเคราะห์วิชาการขาย ทั้ง 5 บท
```

## วิธีเพิ่มหรือแก้ข้อสอบ

เปิดไฟล์ใน `data/` แล้วเพิ่มลงใน array ที่ต้องการ — `id` ต้องไม่ซ้ำกับข้ออื่นทั้งระบบ

```js
// ปรนัย — ต้องมี 5 ตัวเลือกพอดี, answer คือ index ของตัวเลือกที่ถูก (เริ่มจาก 0)
{ id: 'k5-99', type: 'analysis', q: 'โจทย์ยกสถานการณ์...',
  choices: ['ก', 'ข', 'ค', 'ง', 'จ'], answer: 2,
  explain: 'คำอธิบายเฉลย', ref: 'บทที่ 5 — ชื่อหัวข้อสไลด์' }
// ไม่ใส่ type = เป็นข้อความจำ ('recall') โดยอัตโนมัติ

// เติมคำ — ใส่ ____ ตรงช่องว่าง, accept คือคำตอบที่ยอมรับได้ทุกแบบ
{ id: 'kf5-99', q: 'ข้อความ ____ ต่อ', accept: ['Demographic', 'ประชากรศาสตร์'],
  hint: 'คำภาษาอังกฤษขึ้นต้นด้วย D', explain: '...', ref: '...' }

// จับคู่ — ต้องมี 5 ข้อต่อชุดพอดี คำตอบในชุดต้องไม่ซ้ำกัน และทุกข้อต้องมี ____
{ id: 'ks5-99', title: 'ชื่อชุด',
  items: [ { q: 'คำใบ้ ____', answer: 'คำตอบ' }, /* ...อีก 4 */ ], ref: '...' }
```

การเทียบคำตอบของข้อเติมคำจะตัดช่องว่าง เครื่องหมายวรรคตอน และไม่สนตัวพิมพ์เล็ก/ใหญ่
(`BANT` = `bant` = `B.A.N.T.`) จึงควรใส่คำตอบที่สะกดต่างกันได้ลงใน `accept` ให้ครบ

`bank.js` มีตัวตรวจข้อมูลในตัว — ถ้า `id` ซ้ำ, ตัวเลือกไม่ครบ 5, `answer` อยู่นอกช่วง,
ตัวเลือกซ้ำกัน, `type` ไม่ถูกต้อง, โจทย์เติมคำลืมใส่ `____` หรือชุดจับคู่ไม่ครบ 5 ข้อ
จะขึ้นเตือนใน Console ของเบราว์เซอร์ และทำให้เทสต์ `tests/exam.spec.js` ไม่ผ่าน

### เพิ่มวิชาใหม่

1. เพิ่ม `addSubject({ id, name, en, short, note, icon })` ใน `data/00-subjects.js`
2. สร้างไฟล์ `data/NN-<วิชา>-chXX.js` แล้วเรียก `addChapter({ id, subject, no, title, en }, {...})`
3. เพิ่ม `<script src="data/...">` ใน `index.html` ตามลำดับที่ถูกต้อง

หน้าแรกจะแสดงการ์ดวิชาใหม่ให้เองโดยไม่ต้องแก้ `app.js`
